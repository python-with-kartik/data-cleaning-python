# 📊 Data Cleaning Project using Python

This project demonstrates a real-world data cleaning workflow using Python and pandas.  
It simulates how freelance data cleaning tasks are handled for clients on platforms like Fiverr.

---

## 📁 Project Overview

The raw dataset contained:
- Missing values
- Inconsistent formatting
- Extra spaces in text fields
- Mixed data types

The goal was to clean, standardize, and prepare the data for analysis or reporting.

---

## 🧹 Cleaning Tasks Performed

✔ Removed extra spaces from text fields  
✔ Handled missing values (`Unknown`, `no remarks`)  
✔ Standardized date format (`YYYY-MM-DD`)  
✔ Converted numeric columns to proper data types
✔ Converted sales amount from word to numeric 
✔ Cleaned column names  
✔ Generated a final analysis-ready CSV file
