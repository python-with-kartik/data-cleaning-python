# Data Cleaning Project with Python (Real-World Freelance Example)

This project demonstrates how I clean, fix, and standardize messy CSV / Excel data using Python (Pandas).

## Project Overview

This is a real-world data cleaning project where raw sales data is cleaned and converted into a structured, analysis-ready format.

## What This Project Covers

- Removing duplicate rows
- Handling missing values
- Cleaning column names
- Fixing date formats
- Cleaning currency values
- Standardizing text data
- Exporting clean CSV output

- Python 3
- Pandas
- CSV data handling
- PyCharm
- Git & GitHub

## How to Run the Project

1. Clone the repository:
git clone https://github.com/python-with-kartik/data-cleaning-python.git

2. Install required library:
pip install pandas

3. Run the script:
python clean_data.py

4. Cleaned file will be generated as cleaned_data.csv
